# VASTU HOME · SMM-платформа

Рабочее пространство SMM проекта VASTU HOME по стратегии на октябрь 2026 — март 2027.

## Вкладки

| Вкладка | Что делает |
|---|---|
| Обзор | Текущий месяц плана, ближайшие публикации, открытые ТЗ Ларисе |
| Дашборд | Живая аналитика по пяти площадкам (`dashboard.html`), читает Google-таблицу |
| Стратегия | Презентация стратегии слайдами: разделы, миниатюры, стрелки, полный экран |
| Декомпозиция | Блоки работ × 3 месяца, у каждой ячейки статус |
| Контент-план | Листы Instagram / Telegram / VK / MAX / Pinterest / Идеи в формате рабочей таблицы; из строки можно сделать ТЗ Ларисе |
| Переупаковка | Листы Instagram / Highlights / Telegram / VK / MAX / Pinterest / Воронки и CTA |
| ТЗ Ларисе | ТЗ на контент: задача, что сделать, хуки, речь, текст, сценарий, CTA; копируется текстом для отправки |
| Отчёты | Ежемесячный отчёт: факт по KPI против точки А и цели + решения |
| UTM-метки | Генератор по методике таблицы «Генератор UTM VASTU HOME» + журнал ссылок |
| Инструменты | Проверка текста по tone of voice, резервная копия данных, памятка |

## Как открыть

Статичный сайт без сервера и сборки.

1. **GitHub Pages** (рекомендуется): Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
2. Любой хостинг статических файлов.
3. Локально: открыть `index.html` в браузере.

## Где лежат данные

- **Аналитика** — Google-таблица (ID в `dashboard.html`, переменная `SHEET_ID`), открыта на просмотр по ссылке.
- **Презентация стратегии** — картинки в `slides/`. Новая версия стратегии: выгрузить PDF и выполнить `python3 tools/build_slides.py стратегия.pdf` (нужен poppler-utils).
- **Справочники UTM и лендинги** — `utm-data.js`. Обновление: `python3 tools/update_utm_data.py таблица.xlsx`.
- **Стартовое наполнение** (декомпозиция, переупаковка, контент-план, ТЗ) — `seed-data.js`. Загружается один раз.
- **Всё, что команда вносит в платформе**, — в браузере (localStorage). Перенос и резервная копия: «Инструменты» → «Скопировать данные» / «Вставить копию».

## Передача проекта

Передать права на репозиторий (Settings → Transfer) или добавить команду в Collaborators, передать владение Google-таблицами и сохранить свежую резервную копию данных из «Инструментов».
