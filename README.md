# VASTU HOME · SMM-платформа

Рабочее пространство SMM проекта VASTU HOME по стратегии на октябрь 2026 — март 2027.

## Что внутри

| Вкладка | Что делает |
|---|---|
| Обзор | Текущий этап, прогресс по KPI, решения первых двух недель |
| Дашборд | Живая аналитика по пяти площадкам (`dashboard.html`), читает рабочую Google-таблицу |
| Стратегия | 9 разделов SMM-стратегии: аудит, ЦА, конкуренты, позиционирование, контент, площадки, воронки, KPI, план |
| Контент-план | Неделя по дням, добавление и редактирование публикаций, функция каждой единицы контента, автоматическая сверка ритма площадок |
| Переупаковка | Чек-лист упаковки по площадкам: не начато → в работе → готово |
| Воронка | Основная воронка через Telegram-бот, лид-магниты, доп. источники, обработка входящих |
| Отчёты | Ежемесячные отчёты: факт по KPI против точки А и цели + решения «продолжаем / меняем / тестируем / останавливаем» |
| План внедрения | Задачи на 3 месяца и зоны ответственности |
| Голос бренда | Проверка текста на обещания и запугивание, правила tone of voice, «было → стало», палитра |
| UTM-метки | Генератор по методике таблицы «Генератор UTM VASTU HOME»: лендинг → `utm_source` (источник) · `utm_medium` (канал) · `utm_campaign` (тип контента) · `utm_content` (уникальное поле) · `utm_term` (ID лендинга). Журнал ссылок копируется строками для листа GENERATOR |
| Инструменты | Резервная копия данных, памятка для нового человека в команде |

## Как открыть

Это обычный статичный сайт без сервера и сборки. Варианты:

1. **GitHub Pages** (рекомендуется): Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`. Сайт будет по адресу `https://<аккаунт>.github.io/vastu-smm-dashboard/`.
2. Любой хостинг статики (Netlify, Vercel, Tilda «Zero-блок» не подойдёт — нужен хостинг файлов).
3. Локально: открыть `index.html` в браузере.

## Где хранятся данные

- **Аналитика** — в Google-таблице (ID в `dashboard.html`, переменная `SHEET_ID`). Таблица должна быть открыта на просмотр по ссылке.
- **Справочники UTM и список лендингов** — в `utm-data.js`. Когда в таблице-генераторе появились новые лендинги или источники, выгрузите её в .xlsx и выполните `python3 tools/update_utm_data.py таблица.xlsx`.
- **Стратегия, чек-листы, KPI** — в начале скрипта `index.html` (блок «СПРАВОЧНИКИ»). Править можно прямо в коде.
- **Контент-план, отметки и отчёты** — в браузере (localStorage). Чтобы перенести на другой компьютер или сохранить копию: вкладка «Инструменты» → «Скопировать данные» / «Вставить копию».

## Передача проекта

Чтобы платформа жила без автора: передать права на репозиторий (Settings → Transfer) или добавить команду в Collaborators, передать владение Google-таблицей, и сохранить свежую резервную копию данных из вкладки «Инструменты».
